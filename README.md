# James's MCP Server

A custom MCP server built with the Model Context Protocol SDK.

## Tools
- **get_quote** — returns a random motivational quote.
- **get_crypto_price** — fetches the live USD price of any cryptocurrency (via CoinGecko).

## Tech
Node.js, @modelcontextprotocol/sdk, zod. Connects to Claude Desktop via stdio.

Built by James Ganobi.
